## Yoyu v1.6.4

**If you flashed a board in the last few days and could not find the `Yoyu-Setup`
Wi-Fi, this is why, and this release fixes it.** Nothing was wrong with your
board or your phone: it was never broadcasting.

### New boards could not be set up at all

WPA2 refuses a passphrase shorter than 8 characters. The setup hotspot's
password was `yoyu` — four — so the board's `softAP()` call failed outright and
no network was ever put on the air. The screen still said *"join Yoyu-Setup"*,
because as far as the rest of the firmware knew, it had.

This shipped in **v1.6.0** and has been broken ever since. It stayed invisible
because every board already in the world had Wi-Fi saved and never entered the
setup portal again — the only way to see it was to set up a brand-new board,
which nobody had done since the rename.

**The setup password is now `yoyusetup`.** If you have a board stuck on the
setup screen, update it over USB from the setup page and the hotspot will
appear.

There is now a compile-time check on the passphrase length, so a too-short one
is a build error rather than something you discover by unboxing hardware.

### The setup screen says what the radio actually did

A hotspot that fails to start and a hotspot you simply cannot find look
identical from the sofa. The board now reports the result of bringing the
network up on its serial console, so the two can be told apart.

### Second board: it lights up

Support for the **Waveshare ESP32-S3-Touch-AMOLED-2.16** (2.16", 480×480) took
its first real boot, which turned up two faults that no existing board could
have shown:

- **It panicked on every boot.** Brightness was set before the display bus was
  constructed. On the 2" LCD board that is a PWM write to a pin which exists
  from power-on; on an AMOLED, brightness is a command sent *to the panel*, so
  it crashed before drawing anything. The order is fixed, and guarded so it
  cannot silently depend on ordering again.
- **Every colour came out as its opposite** — white background, black text, blue
  meters. An IPS panel drives its pixels inverted and needs the controller to
  invert back; an AMOLED does not. Whether to invert is now a property of each
  board rather than a value assumed to be the same everywhere.

**This board is still not something to buy.** There is no published firmware
image for it and the setup page still offers only the 2" LCD board. Touch does
not work on it yet either. It is being brought up in the open; the README will
say when it is ready.

### Nothing changes for the 2" LCD board

No behaviour differences on the original board beyond the setup password. If
yours is already on your Wi-Fi, this release is optional — though worth taking,
because the next person you hand one to will need the hotspot to work.

### Upgrading

Over the air from `/update`, or re-flash from the setup page. Wi-Fi, login,
settings and history all survive.
