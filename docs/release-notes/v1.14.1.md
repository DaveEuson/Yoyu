## Yoyu v1.14.1

**The AMOLED board's screen stayed black on v1.14.0.** If you have one, take
this update. The 2" LCD board was not affected.

### What happened

v1.14.0 moved the firmware to Arduino core 3.x, which came with a newer
version of the graphics library. That library changed the constructor for the
AMOLED's display controller: the argument that says whether to invert the
panel is no longer there.

The firmware still passed it. Every argument after it shifted along by one, so
the panel was set up with the invert flag as its width and its real width as
its height. A display zero pixels wide draws nothing.

Nothing complained, because all of those arguments are numbers and a number in
the wrong position is still a number. The board booted, joined Wi-Fi, served
its pages, cycled its screens and answered every request correctly, with a
black panel the whole time. From anywhere except in front of it, it looked
perfectly healthy.

The equivalent constructor for the 2" board still takes that argument, which is
why only one board went dark.

There is now a compile-time check that fails the build if the invert setting is
ever silently dropped like this again.

### Upgrading

Over the air from `/update`, or re-flash from the setup page. Wi-Fi, login,
settings and history all survive.

If your AMOLED is on v1.14.0 with a black screen, it is still on your network
and will still update itself. Open the address it was on and use `/update`, or
re-flash it over USB from the setup page.
